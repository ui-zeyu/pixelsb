# pixelsb

像素级图像查看器，用来看通道数值、相对锚点的偏移，以及单个通道的某一位。

```bash
uv run pixelsb
uv run pixelsb image.png
```

单击图像设置锚点，按住左键拖动平移。右侧的勾选格决定画面和数字由哪些位组成：默认一块格子同时控制两者；勾选工具栏的「分离」后会出现「画面」「数字」两块格子各自控制，数字默认显示原始通道值，「原始值」把数字层复位。行首、列首的复选框选整行或整列。⌘、Ctrl 或 Shift 加单击＝只看这一位。多通道数值逐行显示，放大到格子放得下文字时，数字直接画在像素上，字号随格子自适应。`适配` 铺满窗口（支持小数倍缩放），`1:1` 回原始大小。右侧下方是提取面板：把当前勾选的位按通道顺序、位从低到高拼成字节，同时显示十六进制和 ASCII，搜索框即时过滤。

工具栏的显示过滤器作用在画布和提取两处，写法类似 Wireshark，例如 `rect(50, 50, 100, 100) and B >= R and B >= G`、`50 <= left <= 100`、`0 < R - G <= 100`。字段是 `left`、`top`（别名 `x`、`y`、`up`）和各通道名，通道值是当前勾选位算出的值（未勾选的通道读作 0）；`rect(x0, y0, x1, y1)` 是含边界的矩形，坐标写反会自动交换，可以和其他条件自由组合，也可以 `rect(...) or rect(...)`。不匹配的像素在画布上暗化、不画数字，也不进入提取流；状态栏显示通过计数，表达式出错时红框提示并回退为不过滤。`⌘F` 聚焦输入框，回车立即应用并回到画布；在输入框里打字不会触发画布快捷键。菜单「帮助 → 快捷键」里有完整列表。

调色板图像会同时给出原始索引和查色后的 R/G/B/A。16-bit 灰度按 0–15 位显示。CMYK 等模式会先转成 RGBA，状态栏会标明位平面来自转换后的数据。
