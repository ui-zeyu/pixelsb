# pixelsb

像素级图像查看器，用来看通道数值、位平面，以及任意组合的位。

```bash
uv run pixelsb
uv run pixelsb image.png
```

界面是亮色。菜单栏下面是独占一行的显示过滤器（左端「过滤」，右端显示「通过 N/M」）：输入框是浅灰填充、无边框的圆角框，聚焦时才变白并描主色边，右端的清空叉是浅灰细线（Qt 自带的是深色圆盘图标，`_clear_icon` 换掉了它）。再下面是工具行：左边是缩放组（`−`、滑杆、`+`、当前倍率、`适配`、`1:1`），右边是数值组（进制下拉）。滑杆是对数刻度，每翻一倍占同样的行程，所以 5× 的手柄不会贴在左端。两行里的方框都锁到 `theme.CONTROL_HEIGHT`（28px），高度一致。右侧面板分两节：上节「位选择」，标题行右端是「分离」，下面是 `原图` / `全部最低位` 两颗连体按钮和勾选格；下节「提取」，是搜索框与等宽十六进制视图（偏移列灰色、hex 主色、ASCII 次要色）；偏移是一条画上去的固定栏，顶部还有一条列头（「偏移」、每行 16 字节的列号 `00`…`0f`、`ASCII`）。侧边栏的初始宽度按一整行提取数据算出来（`Inspector.preferred_width()`），所以打开图像后不需要手动拖分隔条；窗口很窄时优先保证画布还剩 260px。画布底色比窗口略深，被过滤掉的像素向底色褪色，光标是琥珀色描边。颜色集中在 `src/pixelsb/ui/theme.py` 的令牌表里。

按住左键拖动平移。右侧的勾选格决定画面和数字由哪些位组成：默认一块格子同时控制两者；勾选面板右上角的「分离」后会出现「画面」「数字」两块格子各自控制，数字默认显示原始通道值，「原始值」把数字层复位。行首、列首的复选框选整行或整列，勾选状态由 `theme.CheckStyle` 手绘：空框是浅灰圆角描边，勾上是主色填充加白色对勾，只勾了一部分（整行/整列里的位只选了部分）是主色描边加一道横杠。⌘、Ctrl 或 Shift 加单击＝只看这一位。多通道数值逐行显示，放大到格子放得下文字时，数字直接画在像素上，字号随格子自适应。`适配` 铺满窗口（支持小数倍缩放），`1:1` 回原始大小。右侧下方是提取面板：把当前勾选的位按通道顺序、位从低到高拼成字节，同时显示十六进制和 ASCII，搜索框同时匹配十六进制、ASCII 和偏移。偏移与列头由 `ExtractView` 画在文本区之外（左、上两条 viewport margin），所以鼠标框选、⌘A、复制拿到的只有十六进制和 ASCII，不会混进偏移；列头跟着水平滚动，偏移栏固定不动。

工具栏的显示过滤器作用在画布和提取两处，写法类似 Wireshark，例如 `rect(50, 50, 100, 100) and B >= R and B >= G`、`50 <= left <= 100`、`0 < R - G <= 100`、`R.raw >= 200`。字段是像素的四条边 `left`、`top`、`right`、`bottom`（像素占据 `[left, right) × [top, bottom)`，即 `right = left + 1`、`bottom = top + 1`）和各通道名（大小写不敏感），通道值是当前勾选位算出的值（未勾选的通道读作 0）；通道名后面可以加属性 `R.raw` 取原始通道值（无视勾选）、`R.bits` 显式写出勾选位的值。矩形可以写 `rect(left=50, top=50, right=100, bottom=100)` 或按顺序 `rect(50, 50, 100, 100)`，与 `left >= 50 and top >= 50 and right <= 100 and bottom <= 100` 完全等价，顺序写反会自动交换，也可以和其他条件组合、用 `or` 取并集。想要「含右边界」的写法直接用比较：`50 <= left <= 100`。不匹配的像素在画布上向底色褪色、不画数字，也不进入提取流；过滤行右端显示通过计数，表达式出错时输入框红框提示、原因写在状态栏，并回退为不过滤。`⌘F` 聚焦输入框，回车立即应用并保留光标（继续输入不会触发画布快捷键），`Esc` 清空并回到画布。菜单「帮助 → 快捷键」里有完整列表。

调色板图像会同时给出原始索引和查色后的 R/G/B/A。16-bit 灰度按 0–15 位显示。CMYK 等模式会先转成 RGBA，状态栏会标明位平面来自转换后的数据。
