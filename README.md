# pixelsb

像素级图像查看器，面向 CTF 的位平面分析与 LSB 隐写提取：任意组合通道位查看画面与数值，用过滤器筛选像素，把所选位拼成字节流。

窗口布局：左侧栏（预留）、中间画布、右侧栏与最右侧的按钮竖条 — 竖条上的按钮切换右侧栏的页面（`▦` 位选择与提取、`ⓘ` 文件信息）。

## 运行

```bash
uv run pixelsb
uv run pixelsb image.png
```

## 功能

- **帧导航** — GIF、APNG、WebP 的多帧在状态栏用 ◀ ▶ 切换，指示器显示帧序号与当前帧延时（帧间隔隐写的入口）；跨帧保留位选择、过滤器和缩放，选择按新帧实际拥有的位自动裁剪。
- **位选择** — 勾选各通道的位，画面与像素数值随之组合；「原图」「全部最低位」一键预设；标题旁两对按钮：`◀` `▶` 按矩阵阅读顺序（R7…R0、G7…G0、B7…B0）逐位看单个位平面，`▲` `▼` 遍历整条通道（R 的所有位 → G → B → 循环）；行首、列首复选框选整行/整列；⌘、Ctrl 或 Shift 加单击只看一位。
- **视图调整** — 工具栏「反相」「灰度」「阈值」三枚开关与阈值输入框：255−原值、按亮度合成、按 通道值>阈值 二值化（先灰度、后阈值、再反相）。只改画面，像素读数仍是原始值，与过滤器、「仅提取像素」叠加；「导出」把当前组合画面（含调整）存为图像文件。
- **显示过滤器** — 类 Wireshark 表达式，画布淡化、提取流与通过计数共用：
  - `rect(50, 50, 100, 100)` 矩形，支持具名 `rect(left=, top=, right=, bottom=)`；
  - `grid(10, 20, 6, 6)` 从起点按步长跳跃取点（步长 1 即逐像素）；
  - 字段 `left` `top` `right` `bottom` 与各通道名，通道名取原始值，加位号取该通道的某一位（`R.0` 是最低位，`R.7` 是最高位），加 `.bits` 取勾选位算出的值；支持 `and` / `or` / 比较 / 算术。
- **画布选区（预览）** — 工具条「选区」工具下拖动框选：拖动与松开都只是预览，画布保留选区框、状态栏显示将写入的 `rect(...)`、尺寸与命中数，此时过滤器不变；回车把 `(原表达式) and rect(...)` 追加进过滤器（原表达式自动加括号，`or` 表达式不会被改变含义），Esc 取消预览。按住空格临时平移。
- **仅提取像素** — 勾选后画布收缩为表达式选中像素组成的小图：`grid` 得到等步长子图、`rect` 得到裁剪；提取流不变。
- **提取面板** — 所选位按通道顺序、每个通道位从低到高拼成字节，每 8 位 1 字节；面板顶部三个控件切换读取顺序：通道排列（RGB / RBG / BGR …，只列参与提取的通道）、位序（先出现的位进字节最高位 MSB 还是最低位 LSB）、扫描顺序（XY 逐行 / YZ 逐列），默认是「原序 · MSB · XY」，切换后过滤器命中的像素同样按该顺序流入。整条 8 位通道全选时，LSB 得到的正是原始字节值（MSB 为按位反转的字节）。十六进制与文本分成两栏，文本栏表头显示当前编码（`ASCII ▾`），点击即可在 ASCII / UTF-8 / UTF-16LE / UTF-16BE 之间切换（多字节字符跨行时整字显示在结束它的那一行，只有真正非法的字节才显示替换符；被搜索隐藏的行不与相邻行拼接）；两栏各自独立选中复制（拖文本不会带上十六进制），支持按十六进制、ASCII 或偏移搜索。
- **提取流检测** — 提取面板顶部的检测条显示整条流的类型：[magika](https://github.com/google/magika) 的模型优先，模型对截断流失语或只猜成文本时由 [filetype](https://github.com/h2non/filetype.py) 的文件头签名兜底；流内的文件签名（PNG、JPEG、ZIP、RAR、7Z、PDF、GZIP、ELF…）与 flag 形态字符串（`flag{…}`、`CTF{…}`、`DASCTF{…}` 等）列成可点击标签：点击跳到对应行并选中字节，所在十六进制列着色（flag 为琥珀色、签名为蓝色）；「保存」把整条流（不受显示行数上限约束）写入文件。
- **文件信息** — 右侧栏第一页（菜单「文件 → 文件信息」同样会切到这一页），三张卡片：文件（名称、路径、格式与通道）、检查（块级清单：每行是单选框、偏移、块名、大小、必需/附属与行尾的一小段可打印文本预览——可打印字节照原样显示、其余显示为点，因此 iTXt/tEXt 的注释直接可读，拼在末尾的另一个文件也会以 `.PNG....` 之类的开头显形；IDAT 按 zlib 流编号归组，单个 IDAT 也算「流 1」、一条流跨多个块只算一组；结构异常以警告显示——拼接的第二个 IEND（Acropalypse，CVE-2023-28303）、假 IDAT（多出的数据流、超尺寸扫描行、流截断、IDAT 不连续）；文件正常时保持沉默。两个控件各管一件事：单选框是画布——每个可渲染单元一个单选框，即独立的块各一个、一条 zlib 流只在它的首块上一个（同流的其余块不再重复出现，靠「流 N」标注关联，因为它们在画布上是同一张图），选中它就把该单元渲染成像素（打开文件时画布显示的就是流 1，其首块默认处于选中态且不触发重新渲染），画布下方那行始终说明显示的是哪个流或哪一块，渲染失败就在同一行就地说明并把单选框退回画布真正显示的那一块；块名按钮是转储——点击后下方用提取面板同一个转储视图（同一控件、同样的偏移栏与字节标尺）展示该块，高度随内容伸缩，块头与 CRC 着色，标题条给出推测类型与可点击的 flag/签名标签；转储上方同样有一条搜索框，按十六进制、ASCII 或偏移过滤块内的行，语义与提取面板一致。清单里单选框所在的画布流那一行以强调色、正在转储的块以底色标出）、EXIF（基础 IFD 与 EXIF / GPS 子目录的标签）。
- **视图** — ⌘滚轮、触控板捏合或滑杆缩放，拖动平移，像素数值放大后直接画在格子里，`适配` / `1:1` 一键切换。

快捷键见菜单「帮助 → 快捷键」。

## 开发

```bash
uv run ruff format
uv run ruff check
uv run ty check
uv run pytest
```

代码分三层：`domain/` 纯逻辑（模型与状态转换、过滤器编译、位渲染、调整、提取、字节转文本、检测与分类、匹配视图），`io/` 图像加载（含多帧）、容器检查、流分类器、写出，`ui/` Qt 界面（`canvas` 画布与选区、`inspector` 位选择与提取区、`extract_view` 转储面板、`side_panels` 右侧栏竖条与页面切换、`info` 文件信息页、`painting` 绘制原语、`theme` 主题）。

测试在 `QT_QPA_PLATFORM=offscreen` 下运行，不依赖真实显示：逐条用例覆盖领域与界面，`tests/test_properties.py` 另用 hypothesis 把过滤器语法、位选择与渲染丢给参考实现做属性校验。
