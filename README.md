# pixelsb

像素级图像查看器，面向 CTF 的位平面分析与 LSB 隐写提取：任意组合通道位查看画面与数值，用过滤器筛选像素，把所选位拼成字节流。

## 运行

```bash
uv run pixelsb
uv run pixelsb image.png
```

## 功能

- **位选择** — 勾选各通道的位，画面与像素数值随之组合；「原图」「全部最低位」一键预设；标题旁两对按钮：`◀` `▶` 按矩阵阅读顺序（R7…R0、G7…G0、B7…B0）逐位看单个位平面，`▲` `▼` 遍历整条通道（R 的所有位 → G → B → 循环）；行首、列首复选框选整行/整列；⌘、Ctrl 或 Shift 加单击只看一位。
- **显示过滤器** — 类 Wireshark 表达式，画布淡化、提取流与通过计数共用：
  - `rect(50, 50, 100, 100)` 矩形，支持具名 `rect(left=, top=, right=, bottom=)`；
  - `grid(10, 20, 6, 6)` 从起点按步长跳跃取点（步长 1 即逐像素）；
  - 字段 `left` `top` `right` `bottom` 与各通道名，通道名取原始值，加位号取该通道的某一位（`R.0` 是最低位，`R.7` 是最高位），加 `.bits` 取勾选位算出的值；支持 `and` / `or` / 比较 / 算术。
- **画布选区（预览）** — 工具条「选区」工具下拖动框选：拖动与松开都只是预览，画布保留选区框、状态栏显示将写入的 `rect(...)`、尺寸与命中数，此时过滤器不变；回车把 `(原表达式) and rect(...)` 追加进过滤器（原表达式自动加括号，`or` 表达式不会被改变含义），Esc 取消预览。按住空格临时平移。
- **仅提取像素** — 勾选后画布收缩为表达式选中像素组成的小图：`grid` 得到等步长子图、`rect` 得到裁剪；提取流不变。
- **提取面板** — 所选位按通道顺序、每个通道位从低到高拼成字节，每 8 位 1 字节；面板顶部三个控件切换读取顺序：通道排列（RGB / RBG / BGR …，只列参与提取的通道）、位序（先出现的位进字节最高位 MSB 还是最低位 LSB）、扫描顺序（XY 逐行 / YZ 逐列），默认是「原序 · MSB · XY」，切换后过滤器命中的像素同样按该顺序流入。整条 8 位通道全选时，LSB 得到的正是原始字节值（MSB 为按位反转的字节）。十六进制与文本分成两栏，文本栏表头显示当前编码（`ASCII ▾`），点击即可在 ASCII / UTF-8 / UTF-16LE / UTF-16BE 之间切换（每行独立解码，跨行的多字节字符显示为替换符）；两栏各自独立选中复制（拖文本不会带上十六进制），支持按十六进制、ASCII 或偏移搜索。
- **视图** — ⌘滚轮、触控板捏合或滑杆缩放，拖动平移，像素数值放大后直接画在格子里，`适配` / `1:1` 一键切换。

快捷键见菜单「帮助 → 快捷键」。

## 开发

```bash
uv run ruff format
uv run ruff check
uv run ty check
uv run pytest
```

代码分三层：`domain/` 纯逻辑（模型与状态转换、过滤器编译、位渲染、提取、匹配视图），`io/` 图像加载，`ui/` Qt 界面（`canvas` 画布与选区、`inspector` 位选择与提取区、`extract_view` 转储面板、`painting` 绘制原语、`theme` 主题）。

测试在 `QT_QPA_PLATFORM=offscreen` 下运行，不依赖真实显示：逐条用例覆盖领域与界面，`tests/test_properties.py` 另用 hypothesis 把过滤器语法、位选择与渲染丢给参考实现做属性校验。
