# pixelsb

像素级图像查看器，面向 CTF 的位平面分析与 LSB 隐写提取：任意组合通道位查看画面与数值，用过滤器筛选像素，把所选位拼成字节流。

## 运行

```bash
uv run pixelsb
uv run pixelsb image.png
```

## 功能

- **位选择** — 勾选各通道的位，画面与像素数值随之组合；「原图」「全部最低位」一键预设；行首、列首复选框选整行/整列；⌘、Ctrl 或 Shift 加单击只看一位。
- **显示过滤器** — 类 Wireshark 表达式，画布淡化与提取共用：
  - `rect(50, 50, 100, 100)` 矩形，支持具名 `rect(left=, top=, right=, bottom=)`；
  - `grid(10, 20, 6, 6)` 从起点按步长跳跃取点（步长 1 即逐像素）；
  - 字段 `left` `top` `right` `bottom` 与各通道名，通道可加 `.raw`（原始值）、`.bits`（勾选位值），支持 `and` / `or` / 比较 / 算术；
  - 工具条「选区」工具下拖动框选，回车把 `rect(...)` 填入过滤器，Esc 取消，按住空格临时平移。
- **仅提取像素** — 勾选后画布收缩为命中像素组成的小图：`grid` 得到等步长子图，`rect` 得到裁剪；提取字节流不受影响。
- **提取面板** — 所选位按通道顺序、位从低到高拼成字节，十六进制 + ASCII 对照，支持搜索。
- **视图** — ⌘滚轮、触控板捏合或滑杆缩放，拖动平移，像素数值放大后直接画在格子里，`适配` / `1:1` 一键切换。

快捷键见菜单「帮助 → 快捷键」。

## 开发

```bash
uv run ruff format
uv run ruff check
uv run ty check
uv run pytest
```

代码分三层：`domain/` 纯逻辑（模型、过滤器编译、位渲染、提取），`io/` 图像加载，`ui/` Qt 界面；测试在 `QT_QPA_PLATFORM=offscreen` 下运行，不依赖真实显示。
